# 架构图集（Archify 全项目图集 + 导航站）

## 需求

用 archify 技能把本项目「完整详细」地画出来：整体与各个部分的架构图、流程图等，新建一个「架构图」文件夹保存；
并明确 **Java 后端当前已在阿里云 ECS 三节点部署**，部署视图要反映这一点。

按技能的项目图集（project atlas）路径执行：先做证据发现与覆盖矩阵，再逐张出图（每张独立过验收门），
最后组装导航层（index + 组件说明页）。

## 验证方式与证据

1. **逐图四门**：每张图跑 Archify `finalize --repo-root . --quality showcase`，四门（validate / deliver /
   check --require-provenance / browser-check）全部通过，收据见 `架构图/diagrams/review-<n>/`；
   spec/artifact 的 sha256 汇总在 `架构图/README.md`。浏览器门用到本机 Playwright 自带 Chromium
   （`ARCHIFY_CHROME` 指向 `~/.cache/ms-playwright/chromium-1243/chrome-linux64/chrome`）。
2. **引用巡检**：13 份候选的 111 条唯一 `sources` 逐条按 `git show HEAD:<path>` 核对路径与行号范围，
   0 条越界；原始日志 `eval/verification/atlas-20261005/citation-audit.txt`。巡检中修正了 3 处锚点错位
   （`dispatch.py`、`session.py` 的行号越界，以及 `ha-cluster.md` 的 RabbitMQ/Redis/Nacos 行号）。
3. **站点自检**（浏览器）：本地 HTTP 服务 + Chromium 无头截图检查——首页总览 iframe 正常、
   说明页图文正常、窄屏 430px 重排正常；站内链接 0 失效；截图存
   `eval/verification/atlas-20261005/`。据此修掉了一处真实缺陷：后端图卡片里
   `smartlect_admin/user/...` 长斜杠串溢出相邻卡片（已改写文案并复跑四门）。
4. 每张图的 `visualReviewRecommendation`（咨询性）已如实登记在 `架构图/README.md`。
