# 改动记录

按 [AGENTS.md](../../AGENTS.md) 约定，本工程所有改动交付前必须记录到 `docs/改动记录/YYYY-MM-DD/功能点.md`（Asia/Shanghai 日期）。

## 规则

- 每天一个目录，每个功能单独一个 `功能点.md`；同日同功能补充写回原文件，保留阶段失败与复测记录。
- 跨天的后续改动：建立当天目录并在文首链接前次记录。
- 每条记录需包含：需求、具体变更、关键源码、验证方式与证据、未完成项、关联代码版本；涉及配置或数据时补启用与回滚说明。
- 计划、实现、回归、真实外部链路和效果验收分别标明；未知指标写未知，测试通过不替代外部服务可用或生产效果结论。
- 原始证据放 `eval/verification/` 并用相对链接引用；不把凭据、真实数据库或买家原文写入记录。
- 证据体积上限：单文件建议 ≤5MB；超限的证据只留在本机 `artifacts/`（不入库），记录中注明留存位置与指纹，避免仓库膨胀。
