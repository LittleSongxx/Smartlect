# 子智能体消融实验：开关实现、调优与配对对照

日期：2026-10-06 ｜ 状态：全流程完成（Stage 0-4），报告见 [eval/verification/subagent-dispatch-live-20261006/ablation-report.md](../../eval/verification/subagent-dispatch-live-20261006/ablation-report.md)

## 需求

验证 Supervisor-Workers（task_dispatch 子智能体并行）相对单 Agent 是否有真实收益。
预注册设计：唯一架构差异为工具可见性；先双臂各自调优至收敛（冻结判据：连续两轮
无提升）再配对对照；共享组件改动双向传播。

## 具体变更

1. **消融开关**（`SMARTLECT_DISPATCH_ENABLED`，默认开）：关闭时 task_dispatch
   结构性不可见（可见面、schema、调用闸三联动）；臂别经 `audit.dispatch_enabled`
   落库。生效提示词为 DB 模板且不含派发措辞，两臂系统提示词逐字节相同。
2. **切臂工具** `scripts/ablation_arm.py`：status / arm A / arm B 一键完成
   开关 + assistant 重启 + 健康检查 + 同文校验。
3. **A 臂调优中修复的四个真实缺陷**（均单测锁定，累计 30 个 dispatch/消融相关测试）：
   bind_tools wire 格式转换、visible_sub_scope 可见面交集、SUB_MODEL_ATTEMPT_LIMIT=4
   防子智能体烧穿全局预算、子回执 SKU 卡片结构化透传（主上下文可合法选品）。
4. task_dispatch description 调优为 v3 措辞（并行检索优先、比较建议直查、单点直查）。

## 验证方式与证据

- 正式对照（冻结双臂、每题 3 试验、配对检验）：
  倾向层 A 83.3% vs B 94.4%（p=0.625）；中性层 A 97.1% vs B 91.4%（p=1.000）；
  成本 A 高 2-4%，时延持平；中性层 A 零误触发。
- 结论：持平偏 B——机制有效（触发时子任务 100% 成功、预算/透传/降级闭环），
  当前任务分布下无显著收益；倾向层失分根因为共享层终答选品遵循缺陷（保留为测量结果）。
- 全部 run 带 provenance，未写入 official 基线；holdout 未触碰。
- assistant 全量 303 用例通过（64 skip）。

## 后记（同日晚间）：透传包装层修复与倾向层重跑

复盘发现 v4/v5 的 SKU 透传因 invoke 返回 `{'data': …}` 包装读错层而完全未生效——
首轮倾向层 A 臂 83.3% 的读数因此失真（3 个失败全是透传失效下无法合法选品）。
修复后重跑 A 臂倾向层全集：**18/18 全过（100%）**、触发 7/18、透传命中 7/7；
配对 A 胜 1 / B 胜 0 / 平 17（p=1.000），代价 token +20%。报告已以后记修订，
结论由"持平偏 B"修正为"倾向层修复后略偏 A、整体仍无显著收益"。
证据：tuneA-v6、tuneA-v6b。
