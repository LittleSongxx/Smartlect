# Smartlect 商家工作台

独立 Vue 3 / Vite 7 应用，从本项目冻结管理端取材，使用本目录源码与锁构建。只连接 Smartlect Gateway，监听 `127.0.0.1`，默认地址 `http://127.0.0.1:18181/admin/`。来源、许可证与保留版本见 [SOURCES.md](SOURCES.md)。

```bash
npm --prefix web/admin ci --ignore-scripts
npm --prefix web/admin run test
npm --prefix web/admin run build
```

服务启动由根项目 `scripts/dev.sh` 管理，统一配置字段为 `SMARTLECT_WEB_ADMIN_PORT` 和 `SMARTLECT_GATEWAY_URL`。本目录的 `npm run dev` / `npm run preview` 同样使用 loopback 与 `strictPort`，不接受端口占用后自动换端口；开发和预览均将 `/admin-api` 同源代理到 Gateway。

管理员使用 Java 图片验证码登录。前端不读取 `adminToken`，无浏览器角色选择或内部认证令牌。每次 Growth 写请求先核对当前 merchant 会话并取得 CSRF；登录失效或账号变化清除旧界面。刷新只读取状态，不重放审批、投放或回复。

页面包括：活动/素材草稿、明确授权审批及绑定资源版本、累计账户/花费/曝光/点击、启用/暂停/恢复/预算与素材动作、库存观测和原始回执、知识草稿/新版本/正文读取/发布/撤回，以及人工工单接管/回复/结束。广告 SKU 字段使用 Java 的裸 `propertyValueIdHash`，商品 ID 独立填写；商品和库存最终由服务端核实。

F5 增加经营助手：目标、可选产品范围/计划预算约束、真实模型或规则规划、持久运行状态、观测事实/消费水位/成熟度、候选诊断与证据、计划动作与回执，以及经验 DRAFT 的明确审核。运行结果不确定时保留原 `request_id`，已知运行最多进行 120 秒/60 次只读查询；刷新不会启动新模型或重放动作。无新观测由服务器返回等待状态。实际 `model_mode` 优先读取运行 result/context，Token/费用按实际 `model_attempts` 记录汇总，未报告项显示未知。

顶栏经营范围仅来自 `/scopes` 的服务端成员资格列表。切换调用 `/scopes/select`，使用新的 actor/CSRF 并销毁旧范围的页面、待写请求与计划审批状态；旧在途响应通过客户端 epoch 拒绝。不能填写任意 scope。活动草稿支持 `/ads/catalog` 返回的真实产品/SKU选择器，原标识入口保留在展开区；列表里的价格只用于展示，提交仍由 Java/受控服务验证。

经营页跳到授权审批时固定所见计划 ID/版本、目标与产品范围，并附 `merchant_plan_id`；授权范围、资源版本与完整计划仍须商家勾选明确批准。推荐策略权限另外列出排序方式、组别及 0–20 整数的权重/候选数量上限，首次审批不自动扩大范围。批准后返回经营页，由受控执行器核对授权并执行或恢复回执；前端不自动批准经验或新 grant。

操作拒绝会保留原因并只读刷新，显示可能已经提交的售罄保护暂停。网络结果不确定时可以查询原动作回执、显式使用原幂等键重试；没有自动重发写操作。审批正文改动或刷新资源后必须重新勾选明确批准；服务端再次比对审批时的活动/素材版本。

当前测试是模拟 HTTP 的前端契约测试。它们覆盖请求和交互保护，不代表已经完成真实浏览器、MySQL、模型或投放闭环验收；真实服务验证由根阶段统一串行执行。人工页当前仅展示现有工单证据与最近人工回复，完整会话上下文读取待 F6 管理详情接口接入。
