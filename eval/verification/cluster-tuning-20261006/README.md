## 这批数据能得出什么、不能得出什么

**能得出**：连接池 8→10 对吞吐无可观测影响（±3%，轮间噪声内）。
同一份 pool=8 配置在不同 JVM 热态下吞吐差 64%（860 vs 525 req/s），
**热态是本环境的主要变量，不是这些参数**。

**不能得出**：任何"最优参数值"。因为变体之间的预热状态尚未做到真正对齐
（稳态判据收敛到的平台 ≠ 数小时混合负载后的状态）。
在预热协议固化（建议按累计请求数预热，如 20 万请求）之前，不要基于这批数据调参。
